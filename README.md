### 1. [Third-Person Shooters Prototype Game](https://github.com/IkbalGumilar/Third-Person-Shooters-Prototype-Game)

**Category:** Game Development<br>
**Technology:** Unity · C#<br>
**Status:** Active prototype development

A Unity third-person shooter prototype focused on data-driven combat, enemy encounters, inventory management, localization, platform UI, and status effects.

#### Highlights

- Third-person movement with free-look camera, aiming, crouching, crawling, jumping, rolling, and melee actions.
- Combat systems for handguns, revolvers, assault rifles, shotguns, and sniper weapons.
- Weapon data managed through ScriptableObjects, including ammunition, magazines, reload behavior, recoil, spread, critical hits, knockback, and penetration.
- Player systems for blocking, guard break, knockback, knockdown, recovery, stealth melee, and weapon melee.
- Grid-based inventory with drag-and-drop interaction, item sizes, quick weapon slots, item previews, item dropping, and pickup interactions.
- Enemy systems covering patrol, chase, melee, ranged attacks, shields, support enemies, bosses, loot drops, and pooled spawning.
- Health, regeneration, shields, buffs, debuffs, consumables, stamina, and stackable status effects.
- Boss encounter flow with warning UI, boss health display, mission completion, ending camera movement, and credits.
- English and Indonesian localization support.
- Desktop, WebGL, and mobile/touch control paths.

The project also includes a playable WebGL prototype:

### 2. [Cek PBB Cianjur](https://github.com/IkbalGumilar/Cek-PBB-Cianjur)

**Category:** Application Development<br>
**Technology:** Dart · Flutter<br>
**Primary platform:** Android, with Windows and Linux support

An application created to help village and subdistrict staff in Cianjur check and manage residents' PBB information through the official service portal. The application is distributed directly to staff devices rather than through the Play Store or App Store.

#### Highlights

- Check PBB bills by NOP and view payment status by tax year.
- Generate QRIS payments and, on Android, support Bank BJB Virtual Account payments.
- Scan NOP information from STTS/SPPT or other tax documents with local OCR on Android.
- Import many NOP records from text, CSV, XLSX, or XLS files.
- Keep a block-based payment record with filters, totals, and export to PDF, Excel, or CSV.
- Print or save STTS/SPPT documents and payment evidence.
- Create encrypted daily backups when new data is available.
- Provide staff monitoring with login, MFA verification, regional payment data, realization, receivables, and collective payments.
- Check social assistance-related data and provide an experimental vehicle information feature.
- Check for new releases from GitHub directly inside the application.

The project demonstrates application development that connects user-facing workflows, document processing, local OCR, payment flows, reporting, and operational data management.

### 3. [Wedding Organizer Application](https://github.com/IkbalGumilar/Wedding-Organizer-application)

**Category:** Web Application Development<br>
**Technology:** PHP · Laravel · Filament · Livewire · Blade · Tailwind CSS · MySQL/MariaDB

A Laravel monolith for Atha Decoration, a wedding organizer business. The application combines a public catalog, customer accounts, booking workflows, event operations, and a Filament administration panel in one project.

#### Highlights

- Public website with home, company information, wedding packages, gallery, portfolio, contact, and WhatsApp call-to-action features.
- Responsive mobile-first interface built with Blade and Tailwind CSS.
- Customer registration, authentication, profile management, password reset, and password confirmation.
- Package browsing with detailed sections and flexible content.
- Booking flow from data entry to review, terms approval, and confirmation.
- Booking snapshots that preserve package names, prices, package contents, and terms at the time of booking.
- Availability calendar with a maximum of three bookings per date.
- Customer access limited to the customer's own bookings and event information.
- Admin dashboard for customers, packages, gallery, bookings, event details, vendors, and manual payment status.
- Role-based authorization that prevents ordinary customers from accessing admin resources.
- Validated gallery uploads for JPEG, PNG, and WebP files.
- Feature tests, PHPUnit, Laravel Pint, dependency locking, and a structured local development workflow.

This project represents my interest in building business-oriented web applications with clear customer journeys, data validation, authorization, and administrative tools.
