## About Me

I'm a mobile app and game developer focused on building practical digital experiences with clean, maintainable, and well-structured code.

My main areas of interest are mobile application development with **Flutter**, game development with **Unity**, and interactive experiences with **Unreal Engine**. I enjoy turning ideas into functional products, investigating bugs, and continuously improving the way a project is designed and built.

I am currently open to:

- Full-time or part-time opportunities in software, mobile, or game development.
- Freelance projects for local and international clients.
- Technical collaboration, code review, debugging, and knowledge sharing within developer communities.

- Build cross-platform mobile applications with Flutter and Dart.
